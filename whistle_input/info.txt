FILES IN 'whistle_input'
========================

Main files (Exercise 2):
    whistle-input-pyglet.py     (Part a)
    whistle-input-pynput.py     (Part b)
-----------------------------------------
Part a: Pyglet app displaying a vertical stack of rectangles, one of which is
visually selected. Whistling upwards moves the selection up, whistling downwards
moves it down. A brief text label provides visual feedback on detection.

Part b: Headless script (no window) that detects upward and downward whistle
chirps and fires real system-wide arrow key presses using pynput, allowing
navigation of arbitrary GUI menus by whistling.

Helper file: audio_sample.py
------------------------------
Utility script for visualizing live microphone input as a waveform using
pyqtgraph. Used during development to inspect the audio signal.

HOW TO RUN
-----------
Part a (pyglet interface):
    python whistle-input-pyglet.py

Part b (system-wide pynput):
    python whistle-input-pynput.py

For Part b, run the script in the background, then switch focus to any GUI
application and whistle to navigate it.

CONTROLS
---------
    Q / ESC     — quit (pyglet version only)
